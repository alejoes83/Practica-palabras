# Practica-palabras
## Aplicacion para estimular el habla en niños pequeños con sindrome de Down.

- Se pueden agregar las palabras que desee con una imagen real o por defecto se tienen dibujos.
- La pestaña "Palabras": escribe la palabra, toca 📷 Foto (el celular le deja elegir entre tomar una foto en el momento o usar una de la     galería), graba su voz y toca Guardar palabra.
- Fotos reales: en la pantalla de juego la foto aparece grande, con la palabra debajo. Las palabras sin foto siguen mostrando el dibujito.
- Cada palabra guardada tiene botones para Oír, Voz (volver a grabarla), Foto (poner o cambiar la foto) y Borrar.
- Biblioteca de dibujos con 120 emojis en cinco grupos: Familia, Animales, Comida, Cosas (casa, ropa, juguetes, transporte) y Cuerpo y        acciones. Al agregar una palabra, toque 😀 Elegir dibujo y escoja uno.
   La app sugiere el dibujo sola para palabras comunes. Si escribe "agua", aparece 💧; con "perro", 🐶; con "pan", 🍞. Si no le gusta, lo   cambia.
- En las palabras ya guardadas hay un botón nuevo, Dibujo, para cambiarlo cuando quiera.
- Si la palabra tiene foto, se muestra la foto, y el dibujo queda de respaldo.
